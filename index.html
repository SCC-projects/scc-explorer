SCC Explorer — applications

Static, server-free versions of the research applications of the SCC Explorer platform on the history of the Congregation of the Council. This build ships with synthetic data that exercises every feature; the research datasets themselves are published on the platform. Everything runs in the browser, from a web server or straight from disk.

This is a demonstration of the application functionalities. With this code any historical timeline or Bibtex application can be created. The real web-site with the actual data is available on the SCC Explorer.

Search References
Bibliographic catalogue.
  • general and per-field search, period slider
  • hierarchical keyword tree
  • BibTeX export of results or selected rows
Build Graphs
The same catalogue as charts.
  • bubble, bar and pie charts on any two columns
  • drag a rectangle to list the records it covers
  • export as PNG, CSV, Excel or BibTeX
Timeline
Points, ranges and background periods.
  • Julian / Gregorian dating across the 1582 reform
  • papal calendar and Easter dates
  • cross-links between cards, deep links
