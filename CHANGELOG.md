## [0.9.0] — 2026-10-04

First public release of the code, with synthetic data.

### Added
- Synthetic datasets generated by `tools/generate_dummy_data.py`
  (deterministic): 60 bibliographic records, 37 timeline entities.
- `tools/build_references.py` and `tools/build_timeline.py`, with a
  `--check` mode used in CI.
- One keyword taxonomy, `references/keywords.js`, shared by Search
  References and Build Graphs (previously duplicated in each app).
- `timeline/config.js`: every dataset-specific setting of the Timeline
  (groups, reference chronology, card templates) moved out of the engine.
- Documentation in `docs/`, community files, CI and GitHub Pages workflows.

### Changed
- Libraries pinned to exact versions on jsDelivr with Subresource Integrity.
- "Select all" behaves the same in both reference apps: it ticks every box
  of its panel if any is unticked, and clears them otherwise.

## Milestones before the public release

These versions ran only on the SCC Explorer platform.

### 2026-10-01 — Early access 0.9
- Early access version 0.9 of the platform launched. The data are still in
  progress.

### 2026-08-18 — Calendars in the Timeline
- Switch between the Julian and the Gregorian calendar, and a papal
  calendar (regnal years on the axis and in the cards).
- Easter dates for every year (Julian computus to 1582, Gregorian from 1583).
- All dates synchronised across the three calendars; cards show the
  calendar marks.

### 2026-07-13 — Guide and documentation
- User guide and documentation of the Timeline rewritten for the new
  application and its functionality.

### 2026-05-19 — Timeline data and functionality
- The cardinals timeline merged into the main timeline.
- Visual style of the timelines updated.
- Cross-links between cards.

### 2026-04-14 — From R Shiny to JavaScript
- All applications converted from R Shiny to static JavaScript for
  performance and usability; no server required.
